# Project Rules - Controle de Embarques de Transportes em Eventos

## Execution and Approval Workflow
- **Continuous Execution**: Once the user approves an implementation plan, the agent must proceed with all subsequent tasks, improvements, and sub-steps without pausing to request confirmation or permission at each stage. This ensures a faster, smoother, and more fluid development process.
- **Confirmation Policy**: The agent should confirm this programming/workflow behavior for all tasks in this project.

## Language Rule
- **Idioma das Respostas**: Toda comunicação com o usuário e documentações, explicações e retornos gerados pelo agente devem ser obrigatoriamente no idioma **Português**.
